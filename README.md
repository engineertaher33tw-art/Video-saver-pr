📌 الحقيقة:
بناء ملف APK من مشروع Python/Kivy يحتاج خادم Linux قوي يعمل
30-60 دقيقة. لا يوجد طريقة "سحرية" للحصول على APK في ثوانٍ.

✅ الحل المجاني الوحيد المتاح:
GitHub Actions - خوادم Google/Microsoft تبني لك APK مجاناً!

═══════════════════════════════════════════════════════════════
                    📋 الخطوات (7 خطوات)
═══════════════════════════════════════════════════════════════

1️⃣  إنشاء حساب GitHub (مجاني، دقيقتان)
    → افتح: https://github.com/signup
    → سجّل ببريدك وكلمة سر

2️⃣  إنشاء مستودع جديد
    → اضغط زر "+" أعلى يمين الصفحة
    → اختر "New repository"
    → الاسم: video-saver-pro
    → اجعله Public
    → اضغط "Create repository"

3️⃣  رفع الملفات
    → اضغط "uploading an existing file"
    → اسحب وأفلِت كل الملفات في هذا المجلد
    → مهم جداً: لا تنسَ مجلد .github (المخفي)
    → اضغط "Commit changes"

4️⃣  تفعيل GitHub Actions
    → اضغط تبويب "Actions" في الأعلى
    → إذا ظهرت رسالة، اضغط "I understand, enable workflows"

5️⃣  تشغيل البناء
    → في تبويب Actions، اختر "Build Android APK"
    → اضغط "Run workflow" (الزر الأخضر)
    → اختر "debug"
    → اضغط "Run workflow"

6️⃣  انتظار (☕ خذ قهوة - 25-40 دقيقة المرة الأولى)
    → ستظهر نقطة صفراء 🟡 = جارٍ البناء
    → عند الانتهاء بنجاح ستصبح ✅ خضراء
    → إذا فشلت ❌، اضغط "Re-run failed jobs"

7️⃣  تنزيل APK 🎉
    → اضغط على البناء الناجح ✅
    → مرّر للأسفل لقسم "Artifacts"
    → اضغط "VideoSaverPro-APK-1"
    → سيتم تنزيل ملف zip
    → افتحه ستجد ملف .apk داخله
    → انقل .apk لهاتفك وثبّته!
